# 2026-09-15 10:40 — Keep Playwright `tests/e2e` out of the react-scripts Jest run

## Problem
A whole-project `pnpm test` (reported at 10:30) failed every suite before any test ran,
because Jest also collected the Playwright specs in `chess-frontend/tests/e2e/` and they
throw `ReferenceError: TransformStream is not defined` under jsdom.

## Cause
`pnpm test -- <args>` forwards a literal `--` to `react-scripts test`. Jest then treats
every later argument, including CRA's own `--config {...}` and `--env jsdom`, as a test
pattern and searches for its own config. With none found, `rootDir` becomes the project
root, so `tests/e2e/*.spec.js` is collected. Without the stray `--`, CRA's config
(`roots: ['<rootDir>/src']`) wins and e2e is never collected.

CRA 5 does not allow `testPathIgnorePatterns` in `package.json` `jest`
(`createJestConfig` lists the supported keys and exits 1 on anything else), so the ignore
belongs in a config file.

## Change
`chess-frontend/jest.config.js` (new): rebuilds the CRA Jest config via
`react-scripts/scripts/utils/createJestConfig` (same transforms, setup files and jsdom
environment) and sets
`testPathIgnorePatterns: ['/node_modules/', '<rootDir>/tests/e2e/']`.
When CRA passes its explicit `--config`, this file is not read, so the normal path is
unchanged.

## Verification (CI=true, chess-frontend)
- `pnpm test --watchAll=false`: 13 suites / 110 tests passed.
- `pnpm test -- --watchAll=false` with `jest.config.js`: exit 0, 13 suites / 110 tests passed, no `tests/e2e` spec collected.
- Negative control, same command with `jest.config.js` moved aside: exit 1, `Test Suites: 36 failed, 36 total`, `Tests: 0 total` (the 10:30 failure, reproduced), and every `tests/e2e/*.spec.js` FAILs with `TransformStream is not defined`. The file was restored afterwards.

`pnpm test:e2e` (Playwright) was not run; its config is untouched.
