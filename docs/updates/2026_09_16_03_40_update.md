## The `ErrorCopy` / `authErrorCopy` unblock

`friendlyError(e, what)` took the failing subject as a literal, which kept a
sentence of user copy in every ViewModel (58 call sites). It is now:

```kotlin
fun friendlyError(context: Context, e: Throwable, @StringRes what: Int): String
```

with `error_offline` / `error_generic` and 40 `error_subject_*` resources. The
migration is recorded as a runnable, idempotent script —
`scripts/migrate_friendly_error.py` — which rewrote the call sites, minted the
subjects, and injected `@ApplicationContext private val context: Context` into
every Hilt ViewModel that then needed one. `authErrorCopy` took the same
treatment (`auth_error_login` / `_register` / `_google` / `_facebook` /
`_no_google_account`).

Twenty-two further ViewModels gained the same injection through the batch files
below, so no ViewModel now builds user-facing text from a literal.

## Deliberately left as literals

These are not UI copy, or extracting them would break something real. Each is
commented at the site or explained here:

- **`presentation/legal/LegalScreens.kt` (75 lines)** — the Privacy Policy and
  Terms of Service bodies. Legal text must match the website word for word and
  is not translated by the same process as UI copy; the screen *chrome*
  (`legal_last_updated`, `legal_bullet`, back button) was extracted earlier.
- **`engine/OpeningDetection.kt` (29)** — chess opening names ("Ruy Lopez",
  "King's Indian Defense"). These are international proper nouns.
- **`CCTAnalyzer.classifyMoveAgainstCCT` tags** ("Check", "Capture",
  "Threat", "Positional") — keys, not copy: `CCTControls` switches colours on
  them and `CCTAnalyzerTest` asserts them.
- **`PlayMultiplayerViewModel.KNOWN_WEBSOCKET_ERROR_MESSAGES` and
  `GameWebSocketService`'s matching "Connection lost. Please rejoin the game."**
  — a whitelist compared against the raw server string. Translating one side
  silently breaks the match.
- **`TacticalTrainerViewModel`'s "White"/"Black"** — used with
  `explanation.startsWith(wrongName)` against server-supplied English text.
- **Chat preset messages (`ChatSafetyRules.PRESET_MESSAGES`)** — sent verbatim
  and re-validated server-side against the English list.
- Exception messages, `check {}` / `require {}` text, HTTP headers, date-format
  patterns, JSON keys and SAN notation throughout `engine/`, `data/` and `di/`.

`scripts/count_remaining_literals.py` reports the heuristic count; it went from
537 to 199, and every survivor is in the list above.

## Tooling added (kept in the tree)

- `scripts/migrate_friendly_error.py` — the one-shot `friendlyError` migration.
- `scripts/apply_pending.py` — applies only the batch entries not yet applied,
  so a half-applied multi-file batch can be resumed.
- `scripts/check_string_refs.py` — fails if any `R.string`/`R.array`/`R.plurals`
  reference has no definition, or a name is defined twice. Runs in under a
  second, versus minutes to reach the same error through Gradle.
- `scripts/count_remaining_literals.py` — repo-wide progress meter.
