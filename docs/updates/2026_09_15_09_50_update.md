**Blocker found (existed before this work, not from 01:58):** `handleRequestResume` is a
`useCallback` declared *before* `sendResumeRequest`, and its dependency array
leaves out `sendResumeRequest`/`user` (5748d35, 2025-11). It keeps the
first-render `sendResumeRequest`, and on a fresh page load `user` is still
null, so every click ("Manual Resume Request", "Request Resume") and the
lobby auto-send returned `Missing user or game context.` and **never
POSTed**. The page then showed "Auto-resume may have failed" forever.

**Fix (uncommitted):** `PlayMultiplayer.js` — a `sendResumeRequestRef` is set
right after `sendResumeRequest`, and `handleRequestResume` calls the ref.
Adding it to the deps array isn't possible: the `const` isn't declared yet
at that point.
