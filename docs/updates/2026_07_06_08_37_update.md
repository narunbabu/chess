# Competitive Roadmap: Kid-Safe Chat Layer

Implemented the first roadmap slice from `docs/competitive-roadmap.md`: child-safe in-game chat and moderation controls.

## Changes

- Added server-side chat safety policy with under-13 preset-only chat, URL/profanity filtering, account/org chat disables, and player blocks.
- Added chat report and user block persistence tables with Laravel models and API routes.
- Extended game chat responses and broadcasts with policy and safety metadata.
- Added player-facing report/block controls in multiplayer chat.
- Added an admin dashboard moderation queue for chat reports and user chat-disable actions.
- Added an organization dashboard social-access toggle for org admins.
- Added focused backend feature coverage for preset enforcement, filtering, reporting, and blocking.
