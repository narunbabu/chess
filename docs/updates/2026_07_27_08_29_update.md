## Outcome

All code and repository-controlled blockers from the 2026-07-26 Android
production-readiness audit are closed. Release generation now stops on missing

  configuration. Google Sign-In is compiled from an explicit server client ID
  and its UI is hidden when unavailable.
- Added server-controlled chat shutdown, minor persistence, preset-only
  kid-safe chat for minors, chat-history policy handling, report and block
  actions, and failure feedback.
- Added the complete Stockfish GPLv3 licence in the APK, an open-source licences

- Preserved logged-out password-reset and referral deep links, persisted
  protected links through login, added `/r/{code}`, and scoped verified App
  Links to routes the app handles.
- Added bundled offline puzzle fallback across all five tactical datasets.
- Moved to API 36 with AGP 8.9.1 and Gradle 8.11.1.
- Allowed the throttled native registration endpoint to omit web reCAPTCHA
  while keeping CAPTCHA mandatory on web registration.
- Added eight Android JVM tests and three Laravel feature tests.

## Release-owner handoff

1. Download the Android `google-services.json` for package `com.chess99.app`
   from the production Firebase project and replace
   `chess99-android/app/google-services.json`.
2. Register upload and Play-signing SHA-1 certificates with the Firebase/GCP
   OAuth client. The matching public web client ID is tracked as
   `GOOGLE_SERVER_CLIENT_ID` in `chess99-android/gradle.properties`.
3. Keep the existing `WS_KEY_RELEASE` secret configured; the preflight confirms
   it is present in this environment.
4. Deploy the backend with `CHAT_ENABLED=true`; setting it to `false` is the
   operational chat kill switch and is exposed to clients through `/api/v1/health`.
5. Run `:app:bundleRelease`; it now depends on the release preflight.
6. After Play App Signing enrollment, append the Play signing SHA-256 beside the
   upload fingerprint in
   `chess-frontend/public/.well-known/assetlinks.json`, deploy the frontend
   public asset, and verify the live file returns HTTP 200.
7. Install the Play-delivered internal-test build and manually verify Google
   Sign-In, FCM receipt, Crashlytics, reset/referral links, minor/adult chat,
   report/block, offline puzzles and Stockfish on a physical device.

No Play upload or production deployment was performed.
