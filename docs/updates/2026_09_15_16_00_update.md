# Feature-level Android/web parity audit

Date: 2026-09-15

## Scope

Completed the source-level feature audit requested in `STATUS.md` for the 15
previously unaudited modules in `docs/android-web-parity-gap-analysis.md`:
Dashboard, Championships, Daily Challenges, Tactical Trainer, Puzzles,
Learn, Leaderboard, Referrals, Ambassador, Organizations, Parent,
Profile/Progress, Subscription, Public game viewer, and Chat.

## Method

Compared the Android screen/view-model/API paths with the corresponding web
components, recording the available flows, bounded omissions, and correctness
risks. The parity document now contains a 15-row evidence matrix and a
prioritized P0/P1/P2 follow-up list.

## Key findings

- P0 correctness findings: Learn lesson validation/completion currently uses a
  placeholder lesson ID and local completion; Daily Challenges do not persist
  the daily submit/review flow and use the general leaderboard endpoint; the
  Public Game Viewer calls the authenticated game endpoint instead of the
  public endpoint.
- P1 gaps: Android Tactical Trainer lacks the web CCT/guide/video/navigation
  affordances; Android Leaderboard lacks the tactical category; Parent replay
  lacks PGN export.
- The remaining modules have usable Android coverage but bounded omissions in
  dashboard, championship, referral, ambassador, organization, profile,
  subscription, and computer-game chat capabilities.

## Verification boundary

This was a source audit. It does not claim browser, physical-device,
TalkBack, logged-out deep-link, payment, or authenticated two-client
acceptance. No code, deployment, publishing, account, or credential changes
were made.
