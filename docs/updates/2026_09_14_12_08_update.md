# Post-deploy backend health gate

The deployment workflow now checks out the repository and runs
`chess99-android/scripts/check_backend_health.ps1` with `pwsh` after successful
SSH deployment. Both added steps skip `check_only=true`. The health step
explicitly exits with the script's exit code, so failed probes fail the job.
PowerShell runs on the GitHub runner, requiring no VPS installation.

The manual runbook now requires the same script from the local repository
root immediately after deployment, including after the steps 2-7 wrapper.
It retains VPS service and log checks. Existing unrelated runbook edits were
preserved.
