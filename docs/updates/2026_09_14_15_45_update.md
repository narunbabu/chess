# 2026-09-14 15:45 — Android: guest "Leave game" from root Play Computer routes to Login

## Problem
After "Try as guest" on Onboarding, NavGraph navigates to PlayComputer with
`popUpTo(Onboarding) { inclusive = true }`, so PlayComputer is the only back-stack
entry. Its `onNavigateBack` was `navController.popBackStack()`, which does nothing
on the root — the toolbar Back arrow and the in-game "Leave game" dialog button were no-ops.

## Change (chess99-android, uncommitted)
- `presentation/navigation/NavGraph.kt`
  - `internal fun leaveRouteFor(hasPreviousEntry, rootExitDestination)` — `null` means an
    ordinary pop; otherwise the route to exit to.
  - `NavHostController.popBackStackOrExitTo(...)` — pops when there is a previous entry,
    else `navigate(exitRoute) { popUpTo(0) { inclusive = true } }`.
  - `Chess99NavGraph` gains `rootExitDestination: () -> String = { Screen.Login.route }`;
    PlayComputer and PlayMultiplayer `onNavigateBack` use it (PlayMultiplayer can be the
    root after a persona handoff or deep link).
- `presentation/MainActivity.kt` — passes `rootExitDestination` re-reading
  `coldStartDestination(tokenManager.isLoggedIn(), onboardingPreferences.hasSeenOnboarding())`
  at leave time: guest (onboarding marked seen by `OnboardingScreen.exit`) → Login,
  first run → Onboarding, signed-in root → Home.
- Ordinary stacks (Login → guest → PlayComputer, Home → PlayComputer) are unchanged: still a pop.
