- 2026-09-02: **Takeback is broken far more widely than this file said** - root cause verified, fix not yet written. The backend broadcasts `game.undo.request`; the web client subscribes as `'.undo.request'`, and Echo strips the leading dot, so it binds `undo.request`. The names have never matched, on any platform: Android hard-binds the same wrong names. **No undo event has ever been delivered to any client, human-vs-human included** - so `docs/android-web-parity-gap-analysis.md:169`, which records human-vs-human takeback as working, is wrong; that check only ever confirmed an HTTP 200 and the button changing to "Asked". Same defect class on Android for draw offers: it binds `draw.offered` where the backend emits `draw.offer.sent`, so **draw offers are dead on Android**. Separately there is no responder for a synthetic opponent and no timeout anywhere, so "Asked" hangs by construction. Evidence: `D:\ArunApps\Karta\engagements\E003-takeback-rootcause.md`.
