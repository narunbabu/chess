  played `1.e4`, engine replied `1...e6` — the app's #1 CTA, dead in 100% of
  baseline attempts, now works end-to-end.
- **S4** — native `LegalScreens.kt` with the full Privacy Policy / Terms of
  Service text ported verbatim from the web JSX. Confirmed rendering **with
  airplane mode on**, proving it's genuinely native, not WebView-dependent.
  E-Book removed from v1 (broken WebView).

A session-limit interruption hit mid-wave (all 3 background agents cut off
simultaneously); recovered by inspecting file state directly (git status,
targeted greps) rather than trusting stale "completed" notifications — all
