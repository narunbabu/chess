## Changes

- **New `scripts/rotate-ci-deploy-key.sh`** (owner-only, with `--dry-run`). It runs these steps:
  1. Preflight: `gh auth status` and a login with the admin key.
  2. Create `~/.ssh/chess99_gha_deploy` as ed25519 with no passphrase, or reuse the key if it already exists.
  3. Append the `.pub` line to `narun`'s `authorized_keys` over SSH, only if that line is missing. This avoids `ssh-copy-id`, which Git for Windows may not ship.
  4. Log in with the new key alone (`IdentitiesOnly`) and warn if `sudo -n` needs a password.
  5. Set `SERVER_SSH_KEY` from the file, then `SERVER_USER=narun` and `SERVER_HOST=69.62.73.225`.

  It ends by printing the `check_only` verification commands. Host, user, repo and key paths can be overridden through `CHESS99_*` environment variables.
- `scripts/deploy-notes.md` § CI Deploy Key now points to the script. The manual commands stay in that section.
