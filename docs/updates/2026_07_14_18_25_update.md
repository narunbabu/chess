# 2026-07-14 18:25 — Android: brand theme overhaul + Home redesign

## Context
Owner review: "the starting page and logged-in pages are normal — no proper
designs." Root-caused and fixed the app-wide visual-design problem, then
redesigned the Home starting page. Verified on the signed RELEASE build on
emulator (`com.chess99.app`, prod).

## Root cause of the "generic" look
`presentation/theme/Theme.kt` overrode only 5 Material color roles
(primary/secondary/tertiary/surface/background) and left every *container* and
*surfaceVariant* role at Material3's **purple** baseline. Result: cards, the
Learn stats bar, the difficulty slider, and nav highlights all read as generic
lavender — the app looked like an untouched Material template despite the
green/gold brand.

## Done
- **Complete brand palette** (`Theme.kt`, light + dark): mapped all
  primary/secondary/tertiary container roles, `surfaceVariant`, and the
  `surfaceContainer*` ladder to the board-green + warm cream/gold identity.
  Added themed status-bar icon appearance via `WindowCompat`. Single change →
  **every logged-in screen recolored at once**.
- **Home redesign** (`HomeScreen.kt`):
  - Green gradient hero banner with the Chess99 knight-shield logo + "Welcome
    back / Ready to play?" + tagline (replaces the lone centered heading).
  - Two branded gradient play cards — Play vs Computer (green) and Play Online
    (gold) — with icon chips and a forward chevron.
  - "Explore" 2-column grid filling the former empty white space: Learn,
    Puzzles, Daily, Tournaments, Leaderboard, History — each routing to a real
    destination via existing nav callbacks.
  - Branded drawer header (gradient + logo + tagline).
- **Login polish** (`LoginScreen.kt`): brand logo above the wordmark; wrapped in
  a vertical scroll so the OAuth + guest buttons never overflow on small screens.

## Verified on-device (release build)
- Home: gradient hero + logo, branded cards, full Explore grid render correctly;
  bottom-nav highlight is gold (brand), wordmark green — no purple anywhere.
- Learn: stats bar is now green (was lavender), tabs/icons brand-colored —
  confirms the palette propagated app-wide.
