# 2026-09-15 01:18 — Carbon 3 signed-diff audit (backend)

Follow-up to the 00:48 `getInactiveSeconds`/`getPausedSeconds` fix. Carbon is
3.10.3: `$a->diffInX($b)` returns `$b - $a` **signed** and as a **float**. So
`now()->diffInX($past)` is negative, and a float passed to an `int` parameter
raises a PHP 8.2 "Implicit conversion from float" deprecation, then truncates.

## Behaviour change to know about

`requestResume`: a same-user retry now **replaces** the pending request only
within 10 s (a rapid pause/resume cycle). Between 10 s and the 30 s expiry it
is **blocked** and returns `is_same_user: true` with an integer
`expires_in_seconds`. This is the documented intent of the code, and the web
client already renders that countdown. Previously it silently replaced the
request at any age. Opponent-side blocking is unchanged. Rows with no expiry
are now cleared by the age branches.
