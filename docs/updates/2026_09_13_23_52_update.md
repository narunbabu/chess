## Why Gradle was not invoked

`connectedDebugAndroidTest` installs onto **every** attached device. The only one is
`emulator-5580`, which belongs to another project (VidyaPath). Running the task would
have installed Chess99 on that emulator and tested x86_64, not arm64. Neither is what
the task asked for.

## To unblock (owner)

Connect an arm64 phone with USB debugging on (or pair it over Wi-Fi), then run this from `chess99-android/`:

```powershell
adb devices -l                     # confirm the phone, note its serial
$env:ANDROID_SERIAL = "<serial>"   # restrict the run to the phone
.\gradlew.bat :app:connectedDebugAndroidTest -PDEBUG_TARGET=prod --no-daemon --console=plain
```

If the phone already has a Chess99 build signed with a different key, the install will fail
with a signature conflict. Do not uninstall the existing app to get around it (see `PHONE_TEST.md`).
