## Bug 1 — Gson TypeToken stripped by R8 (FIXED)
Tactical Trainer threw at runtime in release only: *"TypeToken must be created
with a type argument … When using code shrinkers (ProGuard, R8) make sure that
generic signatures are preserved."* `TacticalTrainerViewModel` deserializes
bundled puzzle JSON via `object : TypeToken<List<TacticalPuzzle>>() {}`, whose
generic signature R8 was dropping.
- **Fix**: added the standard Gson keep rules to `proguard-rules.pro`
  (`-keep … class * extends com.google.gson.reflect.TypeToken`, SerializedName
  members, Signature) + kept `presentation.learn.tactical.**`.
- **Verified**: reinstalled the fixed release APK → Beginner Tactics puzzle
  33/500 loads and the board renders. Confirmed on device, not just build-green.

## Bug 2 — Stockfish engine binary never bundled (NEEDS DECISION, pre-existing)
"Play vs Computer" → *"Failed to start engine: Failed to start Stockfish
engine."* The release APK contains **no native libs at all** (no `jniLibs/`,
no `assets/stockfish`). `StockfishBridge.init()` tries to `exec` a `stockfish`
binary that doesn't exist; `StockfishEngine` wraps it with no pure-Kotlin
fallback. This is **device-independent** (not an emulator/ABI quirk) and breaks
every engine-dependent feature:
- Play vs Computer (headline feature; store listing says "Challenge Stockfish AI")
- Companion mode (plays on the player's behalf)
- CCT "best move" analysis
- Game-review engine analysis (`GameHistoryViewModel`)

Not fixed here — bundling requires cross-compiling Stockfish for arm64-v8a /
armeabi-v7a / x86_64 (PIE executables or `.so`) into `jniLibs`, wiring the
extract-and-chmod-exec path, and testing. See release plan doc for options.
